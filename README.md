# ModemApp  
Aplikacja do zarządzania urządzeniami sieciowymi (modemami) oraz monitorowania ich parametrów. Projekt powstał jako praktyczne ćwiczenie architektury aplikacji .NET, integracji z urządzeniami oraz organizacji logiki biznesowej.

## 🎯 Cel projektu
Celem aplikacji jest:
- pobieranie informacji o modemach,
- wykonywanie operacji administracyjnych,
- prezentacja danych w ustrukturyzowany sposób,
- przygotowanie kodu pod dalszą rozbudowę (API, baza danych, UI).

Projekt jest obecnie w trakcie refaktoryzacji do **Clean Architecture**, aby poprawić czytelność, testowalność i skalowalność.

## 🧰 Technologie
- **.NET 8**
- **C#**
- **Warstwowa architektura**
- **Dependency Injection**
- **HttpClient / integracje**
- **System.Text.Json**

## 📦 Funkcjonalności
- Pobieranie danych o modemach  
- Obsługa podstawowych operacji administracyjnych  
- Logiczny podział na warstwy (Services, Models, Helpers)  
- Możliwość łatwej rozbudowy o API lub UI  
- Przygotowanie pod Clean Architecture
